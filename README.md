# Wisdom Geek

This repository is the [Astro](https://astro.build) 5 rebuild of [wisdomgeek.com](https://www.wisdomgeek.com), Saransh Kataria's blog, which is migrating from WordPress.

## Requirements

- **Node.js** 20.3 or later, except 21 (Astro 5 doesn't support it). Developed on Node 24 LTS.
- **Yarn 1** (Classic). `yarn.lock` is a v1 lockfile.

## Commands

Run from the repository root:

| Command                | Action                                                    |
| :--------------------- | :-------------------------------------------------------- |
| `yarn install`         | Install dependencies                                      |
| `yarn dev`             | Start the dev server at http://localhost:4321             |
| `yarn build`           | Build the static site to `dist/`                          |
| `yarn preview`         | Serve the `dist/` build locally                           |
| `yarn fetch-wordpress` | Regenerate posts from WordPress (see [Content](#content)) |

## Content

Posts are generated by `scripts/fetch-wordpress.js` (`yarn fetch-wordpress`), which reads them from the WordPress REST API on wisdomgeek.com and writes each one to `src/content/<path>/<slug>/index.md`, alongside its images.

**Don't hand-edit generated posts**: the next fetch overwrites them. Fix the script and re-run it instead.

`src/content.config.ts` defines one collection, `blog`, which loads every `index.md` or `index.mdx` under `src/content/`. A post's URL is its folder path, so `src/content/<path>/<slug>/index.md` is served at `/<path>/<slug>/`.

Frontmatter fields:

- `title`, `description`, `pubDate`: required.
- `updatedDate`: optional; also used as the post's `lastmod` in the sitemap.
- `heroImage`: optional; image path relative to the post's folder.
- `author`: optional; matched by name against `src/config/authors.json`. Defaults to Saransh Kataria (`SITE_AUTHOR`).
- `categories`: optional; the post's category names.
- `categoryHierarchy`: optional; the post's category path, top level first. Category archive pages are built from it.

## Project structure

```text
├── astro.config.mjs        # site URL; MDX and sitemap integrations
├── public/                 # static files served as-is: favicon, fonts, robots.txt
├── scripts/
│   └── fetch-wordpress.js  # WordPress-to-Markdown import
└── src/
    ├── components/         # UI components, incl. PageLayout.astro (header, sidebar, footer)
    ├── config/
    │   └── authors.json    # author profiles: name, slug, bio, URL, avatar
    ├── consts.ts           # site title, description, URL, author, social links
    ├── content/            # generated posts (see Content)
    ├── content.config.ts   # blog collection and frontmatter schema
    ├── layouts/
    │   └── BlogPost.astro  # post layout
    ├── lib/utils.ts        # category and HTML-entity helpers
    ├── pages/              # routes (see below)
    └── styles/global.css   # global styles
```

Routes in `src/pages/`:

| File                          | URL                       | Page                                                      |
| :---------------------------- | :------------------------ | :-------------------------------------------------------- |
| `index.astro`                 | `/`                       | Home: carousel and latest posts                           |
| `page/[page].astro`           | `/page/<n>/`              | Home pagination                                           |
| `[...slug].astro`             | `/<path>/<slug>/`         | Posts                                                     |
| `[...category].astro`         | `/<category path>/`       | Category archives, for every level of `categoryHierarchy` |
| `author/saranshkataria.astro` | `/author/saranshkataria/` | Author page with Saransh's posts                          |
| `about.astro`                 | `/about/`                 | About                                                     |
| `contact.astro`               | `/contact/`               | Contact                                                   |
| `privacy-policy.astro`        | `/privacy-policy/`        | Privacy policy                                            |
| `rss.xml.js`                  | `/rss.xml`                | RSS feed                                                  |
